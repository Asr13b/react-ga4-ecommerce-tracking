# React GA4 Tracking Demo 📊

A professional implementation of **Google Analytics 4** in React. This project demonstrates how to track user interactions beyond simple page views.

## 🌟 Skills Proved

- **Advanced GA4 Integration:** Initializing `react-ga4` with best practices.
- **Dynamic Event Tracking:** Capturing clicks, form submissions, and error states.
- **Custom Hooks:** Created `usePageTracking` for automated route monitoring.
- **Data Privacy:** Handling tracking consent and opt-outs.

## 🛠️ Implementation Details

- Tracks **Button Clicks** (e.g., "Contact Us" or "Checkout").
- Monitors **User Engagement Time** on specific components.
- Validated via **GA4 DebugView** for 100% accuracy.

## 🚀 Getting Started

1. `npm install`
2. Update `MEASUREMENT_ID` in `.env`
3. `npm run dev`
